Wrap up the scoped change set: the plan's related local changes when a plan is in play, otherwise this session's
work.

- Verify at the smallest conclusive scope, reusing evidence that is already current. Failures
  clearly unrelated to the scope are recorded and do not block.
- Fix or delete what the task found stale. What the task learned belongs in the tree where it would save
  the next agent an hour or a mistake: in its one home, as symptom, cause, fix. Most tasks leave nothing
  to record.
- Review the change set's final state to the review loop in AGENTS.md.
- Declare the path set, land it by the commit-safety recipe, and push.
- A plan only written is committed. A plan whose execution is fully complete is deleted in that same commit.
- Delete the temporary artifacts the work no longer needs: evidence, gates, snapshots, and the clones and scratch projects
  the plan lists or the session created.

If the work cannot honestly be called complete, or the change set cannot be safely determined, stop and report.
