# Web

- The standard is a site a professional studio would ship: deliberate visual design, fast loads, accessible markup, and no rough edges at any screen size.
- Before you call a visible change done, look at it in a real browser at phone and desktop widths, in each theme the site has, using the keyboard alone, with the console free of errors and warnings.
- Measure page weight, load time, accessibility and search basics with a tool, and report the numbers.
