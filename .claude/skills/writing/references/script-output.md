# Script Output

An agent runs a script and acts on what it prints, without opening the source. These rules hold for every line a script under `.claude/scripts` prints, for its help and for what it archives.

- **Every line has a reader and a use.** A line is progress while the caller waits, a condition that needs the caller's action, evidence the caller cites, or the result. A line that only confirms a step went as expected is not printed. A figure only a maintainer of the scripts reads, to tune them, goes to a log the script keeps for its maintainers and not to the terminal.
- **A line reads alone, in plain words.** Write it for someone who knows the project's languages and tools and has never seen this repository. A project term appears only when it is a name the reader types or sees, such as a parameter, a folder or a tag, and the line or the script's help says what it is. Archived lines follow the same rule.
- **A line tells the truth or says it is guessing.** A cause the script inferred reads "usually" or "likely", with the check that confirms it. No line tells the caller to withdraw, queue again or close anything over a guess.
- **A line that needs action ends on the action**: wait, run again once, run without a named switch, fix a named file, or tell the owner. A command the caller must run is printed whole, with its arguments filled in. An `ERROR:` line always ends on its action.
- **One last line.** A script a caller waits on ends every run on `EXIT: <code> <word>: <what happened>. <what to do>.` No other line of the run starts with `EXIT:`, so output relayed from another script is indented. On a failure the lines right above `EXIT:` say what failed.
- **One meaning per tag.** A tag is the uppercase word before the colon, or two joined by a hyphen, and a grep for it finds one kind of line. `WAIT:` is the one tag for progress, and it says what it waits for, for how long so far and until when at most. A continuation line is indented under the line it belongs to.
- **Units a reader uses.** Clock times are local, as `HH:mm` or `HH:mm:ss`. Durations are whole seconds or minutes with the unit, and sizes are GiB with at most two decimals. Never print a UTC ISO stamp, an unrounded number, an empty value where one is missing, a Python repr, ANSI color codes, or a PowerShell error record where a sentence would do. A pid, a path or an id prints whole.
- **The way to call a script is printed.** A script a caller runs has help that gives each parameter, the exit codes with what to do for each, and an example, and it refuses a mistyped argument before anything runs. A script a caller waits on also says in its help how long a run takes and how to run it detached. A script that forwards its remaining arguments to a program names that program in its help, with the argument names it keeps for itself. A wrapper's help names the script it runs. A PowerShell script declares `[CmdletBinding(PositionalBinding = $false)]`, has comment-based help, and catches a mistyped argument with a parameter declared with `ValueFromRemainingArguments`. A Python tool answers `--help`, and prints its usage rather than a traceback on a bad call.
- **A foreseen condition is not a crash.** It prints with its remedy and without a script location. Only a fault nobody foresaw prints where it was thrown, and says the fault is the script's.
