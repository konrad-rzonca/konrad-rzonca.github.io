# Writing

Read `.claude/skills/writing/references/plain-prose.md` when a change is mostly prose, and before reviewing prose.
Read `.claude/skills/writing/references/script-output.md` before writing or reviewing a line a script prints, its help or what it archives.

`references/project.md`, where this repository has it, says what its dev notes or requirements hold. Read it before you write one.

## Before Finishing Any Prose

Ask these questions of each sentence, and reword or cut it when the answer is the one in brackets.

- What would the reader get wrong, or have to go and find, without it? (Nothing.)
- Would it sound as right under a different class or field? (Yes.)
- Would an ordinary refactor make it false without anyone noticing? (Yes.)
- Would a developer new to this repository know every word? (No.)
- Could the reader act on it in a way you did not mean? (Yes.)
- Did you have to read it twice? (Yes.) Split it.
- Can you restate it in plainer or shorter words that lose nothing? (Yes.) Use the restatement. If nothing is left, delete the sentence.
- Would the last clause look good on a poster? (Yes.) Delete the clause.
